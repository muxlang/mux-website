# Mux local search

This package keeps Mux's documentation search offline and client-side. It is
based on `docusaurus-plugin-search-local` 2.1.2; see [UPSTREAM.md](UPSTREAM.md)
and [LICENSE](LICENSE) for attribution. The implementation currently retains
the upstream plugin behavior and options.

Mux maintains this copy to test Docusaurus 4 canary compatibility. Keep changes
small and verify search indexing, search results, and navigation in the website
build before changing the upstream-derived runtime code.
