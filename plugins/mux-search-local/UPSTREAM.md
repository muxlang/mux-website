# Upstream

This small local package is based on `docusaurus-plugin-search-local` 2.1.2 by
Gabriel Csapo, licensed under MIT. Its upstream source is
https://github.com/gabrielcsapo/docusaurus-plugin-search-local.

Mux keeps the runtime files here so it can widen the Docusaurus peer range for
the v4 canary and maintain the plugin with the website. Preserve the upstream
license in `LICENSE` when modifying or distributing this code.
